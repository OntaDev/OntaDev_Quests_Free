## Текстурпак

Ресурспак ReallyWorld в комплект не входит. Для своего сервера используйте собственный ресурспак или тот, чья лицензия разрешает такое использование.

Если вам нужно скачать ресурспак со своего сервера, смотрите нашу статью [«Как скачать текстурпак со "своего" сервера Minecraft»](https://ontadev.site/articles/server-resource-pack). Если в пакете есть чужие материалы, перед публикацией или раздачей игрокам проверьте условия их лицензий или получите разрешение правообладателей.

### Дополнительные функции для администрации

- **Смена иконки из меню:** предмет в курсоре + клик по квесту ->  обновление иконки квеста. Право: `quests.quest.icon`.
- **Редактор наград прямо в меню:** Shift + ПКМ по награде -> изменить её прямо в отдельном меню. Право: `quests.reward.edit`.
- **Проверка награды админам:** ПКМ по квесту -> получить награду без прохождения квестов. Отметка о получении не ставится. Право: `quests.quest.claim`.

## Команды

Основная команда -> `/quests`, 
<br>алиасы(альтернативы) -> `/квест` и `/квесты`.

`{аргумент}` -> обязательный, `[аргумент]` -> необязательный.

| Команда | Действие |
|---|---|
| `/quests` | Открывает текущую страницу |
| `/quests open {страница} [игрок]` | Открывает страницу.<br> Работает из консоли при указанном игроке |
| `/quests skip` | Пропускает текущий квест |
| `/quests reload` | Перезагружает конфиги, переводы и оформление меню |
| `/quests quest create {тип} {кол-во} [моб] {название...}` | Создаёт квест: цель в левой руке, обязательная иконка в правой.<br> Моб обязателен только для `KILL_MOBS` |
| `/quests quest confirm` `/quests quest cancel` | Подтверждает создание в течение минуты или отменяет |
| `/quests quest delete [id]` | Удаляет квест.<br> Без указания id -> с наибольшим ID |
| `/quests quest icon {id или от-до}` | Ставит иконкой предмет из правой руки, например `1-8` |
| `/quests page list` | Показывает список страниц |
| `/quests page info {страница}` | Показывает недостающие квесты и награды |
| `/quests reward create [id]` | Создаёт или заменяет награду: предмет в левой руке, иконка в правой |
| `/quests reward delete [id]` | Удаляет награду.<br> Без указания id -> с наибольшим ID |
| `/quests reward give {id} [игрок]` | Выдаёт предметы для проверки, без команд и отметки о получении |
| `/quests commands add {id} {команда...}` | Добавляет команду консоли без `/`,<br> `%player%` -> ник получателя |
| `/quests commands {list\|clear} {id}` | Показывает или удаляет команды награды |
| `/quests user {ник/UUID} {skips\|quests\|progress} {число}` | Изменяет пропуски, текущий квест или прогресс |
| `/quests user {ник/UUID} rewards list` | Показывает список полученных наград |
| `/quests user {ник/UUID} rewards {add\|remove} {id}` | Изменяет отметку о получении награды, без выдачи предметов |

Типы квестов: `KILL_MOBS` (убить), `BRING_ITEMS` (принести), `BREAK_ITEMS` (поломать),
`BREAK_BLOCKS` (сломать), `CRAFT_ITEMS` (скрафтить), `BREW_POTIONS` (сварить), `ENCHANT_ITEMS` (зачаровать).

В меню: 
<br>**ЛКМ** -> сдать предметы или забрать награду, 
<br>**Shift + ЛКМ** -> пропустить квест.
Команда создания награды сохраняет один стак; повторное создание с тем же id заменяет и её команды.

### Массовый сброс

| Команда | Действие для всех игроков, включая офлайн |
|---|---|
| `/quests reset progress confirm` | Сбрасывает прохождение и очищает список полученных наград.<br> Сохраняет пропуски и сами задания |
| `/quests reset skips [число] confirm` | Устанавливает число пропусков.<br> Без числа -> значение из конфига,<br> `0` -> обнуляет |
| `/quests reset all confirm` | Удаляет все квесты и награды, сбрасывает прохождение и восстанавливает количество пропусков из конфига |

Без `confirm` выводится описание операции. 

## Конфиги

| Файл | Назначение |
|---|---|
| `plugins/OntaDev_Quests/config.yml` | Меню, тексты квестов и наград.<br> `skipsPerPlayer` -> начальные пропуски,<br> `saveIntervalSeconds` -> интервал сохранения |
| `plugins/OntaDev_Quests/messages.yml` | Сообщения и справка команд |
| `plugins/OntaDev_Quests/ru_ru.json` | Переводы предметов, мобов и зачарований |
| `plugins/OntaDev_Libs/settings.yml` | База данных: H2, MySQL или PostgreSQL |

Тексты поддерживают MiniMessage. После изменения `config.yml`, `messages.yml` или `ru_ru.json` выполните `/quests reload`.
Для изменения подключения к БД в `OntaDev_Libs/settings.yml` нужен перезапуск сервера.
Квесты и награды хранятся в БД и создаются командами.

## Права

`quests.open` доступно всем. Остальные перечисленные права по умолчанию доступны OP.

| Право | Назначение |
|---|---|
| `quests.open` | Открывает меню |
| `quests.open.*` | Открывает любые страницы вне очереди.<br> `quests.open.<страница>` -> отдельную |
| `quests.open.others` | Открывает меню другому игроку |
| `quests.skip` | Использует пропуски |
| `quests.quest.create`, `quests.quest.delete` | Создаёт и удаляет квесты |
| `quests.quest.icon` | Меняет иконки командой |
| `quests.quest.id` | Видит номера и описание закрытых квестов |
| `quests.page` | Смотрит заполненность страниц |
| `quests.reward`, `quests.reward.give` | Управляет наградами и проверяет выдачу |
| `quests.commands.add`, `quests.commands.list`, `quests.commands.clear` | Управляет командами награды |
| `quests.user.edit` | Изменяет данные игроков |
| `quests.reset` | Выполняет массовый сброс |
| `quests.reload` | Перезагружает конфиги и переводы |

## Установка

**Paper 1.16.5–1.19.4 / совместимый Purpur**, Java 11+ для плагина. Java сервера -> по требованиям ядра.

1. Установите [LuckPerms](https://luckperms.net/download) и [OntaDev_Libs 0.2.13+](https://ontadev.site/products/2).
2. Скачайте `OntaDev_Quests_Free.jar` из [релизов](https://github.com/OntaDev/OntaDev_Quests/releases) и положите в `plugins/`.
3. Перезапустите сервер, настройте конфиги и создайте квесты командами.
